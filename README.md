# SafeDeal v9.0.2 — Global Anti-Fake Photo

Додано:
- глобальний reverse-image search для «Антифейк фото»;
- пошук точних збігів і візуально схожих фото у відкритих джерелах;
- власна історія SafeDeal працює паралельно з інтернет-пошуком;
- джерела відкриваються окремими посиланнями;
- фото перед відправкою автоматично стискається у браузері;
- якщо зовнішній провайдер не налаштований або тимчасово недоступний, внутрішня перевірка SafeDeal продовжує працювати;
- оновлена політика конфіденційності для цієї функції.

Налаштування Render:
- додай Environment Variable `SERPAPI_KEY` зі своїм приватним ключем SerpApi.
- ключ не вставляй у код і не публікуй у GitHub.

Провайдер:
- Google Lens через SerpApi Image API + Google Lens API.
- SafeDeal не стверджує, що відсутність збігів гарантує оригінальність фото.

Важливо:
- OCR скріншотів, як і раніше, виконується локально у браузері.
- Фото надсилається зовнішньому провайдеру тільки при використанні окремої функції «Антифейк фото».


## v9.0.2
- Антифейк фото тепер пояснює результат простими словами.
- Джерела поділяються на магазини/каталоги, оголошення продавців та інші сайти.
- Показуються 5 головних джерел, решта ховаються під кнопку.
- Велика кількість каталожних збігів не оголошується шахрайством; SafeDeal пояснює, що це може бути нормальне офіційне фото товару.
