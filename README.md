# SafeDeal v9.0 — Big Update

Додано:
- рівень ризику великим текстом, /100 другорядно;
- розпізнавання ймовірної схеми шахрайства;
- «Докази» з джерелом і надійністю, включно з доказами для 0/дуже низького ризику;
- автоматичні знімки об'єкта та «Що змінилося»;
- SafeDeal Passport;
- SafeDeal Watch;
- база пов'язаних об'єктів за номером/доменом/username/email;
- «Поділитися перевіркою»;
- автоматичний SafeDeal Security Report з унікальним ID та друком/PDF;
- режим «Перед оплатою» з чеклістом;
- «Антифейк фото» через perceptual hash у власній історії SafeDeal;
- інтеграція архівних/прихованих відгуків у докази та Passport.

Важливо:
- SafeDeal не може магічно відновити приватний або давно видалений контент, якщо його раніше не бачив і немає архівного доказу.
- Watch у цій версії фіксує зміни, коли об'єкт перевіряють повторно. Для повністю фонового моніторингу потрібен окремий scheduler/worker.
- Антифейк фото зараз шукає збіги у власній базі SafeDeal, а не по всьому інтернету.

Для оновлення заміни всі файли з архіву.
